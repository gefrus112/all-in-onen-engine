# All In One Engine — Wiki

This directory contains the wiki pages for All In One Engine.

## To activate the GitHub Wiki

1. Go to [the repo on GitHub](https://github.com/gefrus112/all-in-onen-engine)
2. Click the **Wiki** tab at the top
3. Click **Create the first page** (this initializes the wiki git repo)
4. Once initialized, the wiki files from this directory can be pushed to the wiki repo
